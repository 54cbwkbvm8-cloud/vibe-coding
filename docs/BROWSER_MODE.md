# DeepSeek 官网（浏览器模式）

## 定位

该模式是可选的独立浏览器壳，不是 `ChatProvider`，也不是 DeepSeek 官方
客户端。软件自己的聊天框、系统提示词和 API 请求在该模式下禁用。

主程序不依赖也不加载 QtWebEngine。用户需要自行构建并导入可选组件后，
才能选择该模式。

## 页面权限边界

- 只加载和显示官网页面，以及用户通过鼠标键盘进行的普通导航。
- 不注入业务脚本，不读取 DOM、页面文字、HTML、网络请求或 Cookie。
- 不自动填入、不自动粘贴、不自动点击、不自动发送。
- 不修改页面样式、User-Agent 或浏览器指纹。
- 不安装请求拦截器，不启动远程调试端口。
- 不绕过验证码、风控、限频或任何反自动化机制。

主框架只允许 `deepseek.com` 及其子域名。白名单之外的链接和
`window.open`、`target=_blank` 新窗口交给系统默认浏览器。页面权限默认
拒绝摄像头、麦克风、定位、通知、屏幕共享、剪贴板读取、MIDI、USB 等
请求；文件上传选择框由用户手动完成，下载不在内嵌浏览器中执行。

## 剪贴板辅助

软件不会把截图或语音文字自动贴到官网。用户主动选择复制后：

- 内容进入 Windows 系统剪贴板；
- 软件尝试使用排除格式避免进入剪贴板历史、云同步或监视器处理；
- 默认 60 秒后尝试清除，但只有剪贴板序列号仍指向本软件写入的内容时才清除；
- 用户可以自行关闭自动清除或调整时间。

## 登录与数据

登录完全由官网页面处理，二维码来自官网页面本身。软件不保存账号密码，
不读取、复制或记录 Cookie 和 Token。

登录状态保存位置：

```text
%APPDATA%\AIQuizOverlay\web_session
```

设置页提供“撤销同意并清除登录数据”。撤销后回到 API 接入，API Key 和 API
配置保持不变。

当前内嵌窗口可用手机号登录和微信扫码。Apple 登录需要跳转到
`appleid.apple.com`，当前会交给系统默认浏览器，因此内嵌窗口不支持 Apple
登录。不会为了登录擅自扩大白名单。

## 构建与导入

组件不随主程序或 GitHub Release 提供。构建和手动导入步骤见
[BUILDING.md](BUILDING.md)。

## 已知限制

- 页面改版、账号限制、验证码、限频和服务繁忙由第三方控制。
- 软件不读取页面状态，因此登录过期或异常提示需要用户在官网页面中处理。
- 组件不会自动更新，需要定期使用新的 PySide6-WebEngine 重新构建。
- 真实扫码、第三方登录、物理 GPU、双屏和混合缩放需要手动验证。
