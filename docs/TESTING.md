# 测试与已知限制

## 自动测试

```powershell
python -m unittest discover -s tests -v
```

自动测试使用：

- 本地模拟 DeepSeek API；
- 本地模拟聊天页面；
- 合成屏幕截图；
- 合成音频；
- 假 Key 和测试占位数据。

自动测试不会登录真实账号，不会读取真实屏幕，也不会录制用户声音。

## 已完成的人工验收

1.0.0 在 Parallels Windows 虚拟机中完成了主要界面、快捷键、悬浮球、
屏幕识别、本地语音、个性化、可选组件和浏览器壳验收。正式验证数量以
Release 说明和对应提交的测试报告为准。

## 模拟测试与真实测试

| 类别 | 说明 |
| --- | --- |
| 自动测试 | 使用模拟 API、模拟网页、假 Key、合成图片和合成音频 |
| 虚拟机人工测试 | 在 Parallels Windows 中验证真实键盘、窗口、托盘和组件进程 |
| 物理真机测试 | 需要在真实 Windows 硬件、显示器、麦克风和网络上完成 |

## 未验证或有限验证

- 物理 Windows 10/11 真机上的 GPU 圆角和合成效果；
- 真实双屏、混合缩放、屏幕旋转和副屏锚点；
- 物理键盘上的全部组合键和 Parallels 拦截情况；
- 真实 API Key、真实账号和真实模型下载网络；
- 真实麦克风的准确率、延迟、噪声和长时稳定性；
- 受 DRM、独占全屏或安全桌面保护的截图；
- 官网浏览器在真实账号、第三方登录、物理 GPU 和长期页面改版下的表现；
- 代码签名和 SmartScreen 声誉。

## 手动测试建议

至少检查：

1. 干净 Windows 环境双击启动；
2. 搜题模式和全局助手各完成一次问答；
3. 区域截图、整屏识别和取消流程；
4. 本地语音转写、取消和静音结束；
5. 悬浮球 40/64/160 px、显隐热键和重启位置恢复；
6. 每个快捷键修改、冲突回滚和恢复默认；
7. 背景、名称、图标和桌面快捷方式；
8. 托盘退出、重启配置恢复和单实例；
9. 无组件时浏览器模式显示导入提示；
10. 导入组件后的风险告知、官网页面显示和切回 API 的进程清理。
