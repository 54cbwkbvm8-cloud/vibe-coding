# 隐私说明

## 屏幕识别

- 只有在用户按下 `Ctrl+Alt+S` 后才会截图。
- 每次只截取鼠标所在屏幕一次，不进行后台持续截图。
- 截图前隐藏本软件的所有可见窗口，等待桌面重绘后再截取。
- 截图只保存在内存中；取消、发送完成、切换模式或退出时释放。
- 未通过首次隐私同意时，快捷键只显示说明，不截取屏幕。
- 截图只发送到用户配置的 DeepSeek API；其他接入方式按其页面说明处理。

## 区域截图

区域截图只响应用户显式操作。选区和缩略图在内存中处理，不写入项目目录或
日志。取消时丢弃图像引用。

## 本地语音

- 只在用户点击麦克风、使用自动聆听或按相应快捷键后录音。
- 音频以 16 kHz、单声道、16-bit PCM 保存在内存中。
- 静音检测使用 WebRTC VAD，达到设定时长或最长录音限制后停止。
- 本地 SenseVoice 转写完成后只把文字填入输入区域，不写音频文件。
- 音频、转写文本和麦克风内容不会写入日志。
- 麦克风隐私同意可以撤销；撤销后不能开始新的录音。

## 官网浏览器模式

- 浏览器壳只加载和显示官网页面，不读取页面内容、DOM 或 Cookie。
- 不自动填入、自动粘贴、自动点击或自动发送。
- 截图和语音文字只复制到系统剪贴板；用户需要自行在页面中粘贴和发送。
- 剪贴板内容会短暂存在。默认在 60 秒后尝试清除，但仅当剪贴板序列号仍
  属于本软件时执行。
- 登录状态保存在本机 `%APPDATA%\AIQuizOverlay\web_session`。设置中可以
  撤销同意、退出登录并清除全部登录数据。

## 日志约束

日志不得包含：

- API Key、Token、Cookie 或认证头；
- 问题、回答、转写文本或聊天记录；
- 图片 Base64、截图内容或音频内容；
- 完整网址、查询参数或页面 HTML；
- API Key 密文和个性化图片的绝对路径。

## 网络目标

API 接入的生产请求固定为：

```text
https://api.deepseek.com
```

模型下载只在用户点击“开始下载”后访问固定白名单来源。打开程序、打开设置、
打开聆听或普通保存不会触发模型下载。

官网浏览器模式的页面资源、登录服务和第三方登录服务由官网页面自身加载；
主框架导航只允许 `deepseek.com` 子域名，其他链接交给系统默认浏览器。
